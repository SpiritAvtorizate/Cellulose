# Sonic 2d Engine
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0-rc.1.

You can use kosinski decompressor for getting palletes, textures, etc.

This goes with a plugin i made for drawing collision masks, chunks, levels.

Arrays consume about 1.5 MB alone, which isnt alot, but would be nice to somehow debloat them without using buffers.
